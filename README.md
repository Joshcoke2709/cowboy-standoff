# Cowboy Standoff

Cowboy Standoff is a 2D western-themed shooter I'm developing in Unity.

The project started as a simple two-player stickman shooter and has grown into a duel game with character customization, different AI difficulty levels, ammo management and round-based matches.

## Features

- Single-player mode against an AI opponent
- Local two-player mode
- Character selection and colour customization
- Multiple AI difficulty levels
- Health and ammo systems
- Six-shot magazines with reloading
- Hay bale cover and environmental obstacles
- Round countdown and scoreboard
- Pause menu and winner screen

## Controls

### Player 1
- A / D – Move
- W – Jump
- S – Duck / Slide
- Space – Shoot

### Player 2
- Arrow keys – Move, jump and duck
- Mouse click – Shoot

In single-player mode, the controls are adapted for one player.

## Built With

- Unity 6
- C#
- Unity 2D

The game is in its final development and testing stage. I'm currently working on AI difficulty, match rules, UI improvements and preparing a WebGL build.

The initial focus is PC, with web and mobile support planned.
